# Prompt-Router Validation & Regression Test Cases

Consolidated validation suite across all three research phases in `research/prompt-router-research-plan.md`:

- **Suite A (Phase 1 — `optimise`):** 6 cases (`research/01-router-optimise-improvements.md`)
- **Suite B (Phase 2 — `write` & `review`):** 6 cases (`research/02-router-write-review-improvements.md`)
- **Suite C (Phase 3 — Portability, Trust Boundary & Integrity):** 8 cases + 5 offline integrity checks (`research/03-router-portability.md`; Case C7 and the two-guide `adapt` invariant restored in Phase 5 consolidation)

**Global invariants across all suites:**
- `write`, `optimise`, single-target `adapt` (`[source unspecified]`), and `review` (with a concrete model) load **at most one** model guide (`references/model-guides/<target-id>.md`).
- Two-model `adapt` (`from A to B`) loads **exactly two** model guides (`references/model-guides/<source-id>.md` and `references/model-guides/<target-id>.md`).
- `review` with no concrete model (or host-only name), unguided context-bloat `optimise`, and `clarify` load **zero** model guides.
- `model-guides-combined.md` is never read at runtime, and `references/model-guides/` is never listed, globbed, or grepped.

### Offline Model-Guide System Integrity Checks (Run Offline, Never at Runtime)

1. **Registry-to-guide 1:1 resolution:** Every `Model ID` in `references/model-registry.md` resolves to exactly one `references/model-guides/<id>.md` file, with zero missing or unregistered guide files (`scripts/build_registry.py --check`).
2. **Valid guide frontmatter:** Every `model-guides/<id>.md` has valid YAML frontmatter with `model` matching its filename/registry `id`, `vendor`, `family`, `aliases`, `last_verified`, and `status`.
3. **Combined-corpus provenance:** Every runtime guide corresponds to a source record in `model-guides-combined.md` (when present in the build workspace), and `model-guides-combined.md` stays excluded from runtime skill context.
4. **Unambiguous aliases:** Normalising (`lowercase`, `trim`, hyphen-join) all `id` and `aliases` tokens across all registry rows produces zero cross-row collisions.
5. **Deprecated guide successor:** Every guide with `status: legacy` declares a valid non-self `successor` present in the registry (or explicitly documents no official replacement).
