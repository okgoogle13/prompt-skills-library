# DeepSeek-V4-Flash

## Reasoning / Thinking
- **One hybrid model instead of two IDs**: `deepseek-v4-flash` supports both non-thinking and thinking; a separate reasoner no longer exists. Thinking is **on by default** (default effort `high`) — if you want V3-style direct answers, you must actively turn it off: OpenAI format `{"thinking": {"type": "enabled" | "disabled"}}` (in the OpenAI SDK via `extra_body`); Anthropic format: the same switch `thinking: {"type": "enabled"|"disabled"}` (`budget_tokens` is ignored), effort via `output_config: {"effort": "low|high|max"}`; Responses API: `reasoning: {"effort": "none|low|high|max"}` (`none` = off). `reasoning_effort` also accepts `none` (thinking off); mapping minimal→low, medium/xhigh→high, ultra→max.
- Effort values: `low | high (default) | max`. Thinking mode ignores `temperature`, `presence_penalty`, `frequency_penalty` (no error, no effect). `top_p` only has an effect in thinking mode (effectively 0.95–1.0, smaller values → 0.95); in non-thinking mode `top_p` is fixed at 1.0.
- The chain-of-thought comes back in `reasoning_content` at the same level as `content`. **Without** tool calls it need not be sent back in follow-up turns; **with** tool calls the intermediate `reasoning_content` must be part of the context concatenation and be sent back to the API.
- Token level (model card): reasoning is framed as `<think>{reasoning}</think>`; non-thinking is encoded by an immediate `</think>` after the assistant marker; with `reasoning_effort="max"` the template prepends a prefix to the system prompt ("Reasoning Effort: Absolute maximum with no shortcuts permitted…"). Three named modes: Non-think, Think High, Think Max (Think Max recommends a context window of ≥ 384K).

## Prompting style
- The system prompt is first-class: the template is `<｜begin▁of▁sentence｜>{system_prompt}<｜User｜>{user_message}<｜Assistant｜>` — it sits right at the front of the sequence.
- **JSON needs three things at once**: the word "json" in the system or user prompt, an example of the desired JSON format in the prompt, and a sufficiently high `max_tokens` so the string does not cut off mid-way. Otherwise control output via **Chat Prefix Completion**: last message `role: "assistant"` with `prefix: True` against `base_url="https://api.deepseek.com/beta"`, combined with `stop` (e.g. `["```"]`) against trailing prose.
- **Prompt order affects cost**: Context caching is active for everyone without code changes, but only hits on a **full prefix match** of a persisted cache unit and works "best-effort" — it follows that static material (system, reference documents) should go first and variable content at the end (not explicitly documented as a recommendation, only demonstrated that way in the examples — unverified); monitor via `prompt_cache_hit_tokens` / `prompt_cache_miss_tokens`.
- Tool schemas come in via the `tools` field; internally, calls are rendered as DSML (`<｜DSML｜invoke name="…">`, parameters with `string="true"` for raw strings, `string="false"` for JSON values) — only relevant when hand-writing tool-call examples. Local deployments: the model card recommends `temperature = 1.0`, `top_p = 1.0`.

## Strengths & weaknesses (prompt-relevant)
- Efficiency tier: MoE with 284B total / 13B activated, mixed FP4+FP8, hybrid attention (Compressed Sparse Attention + Heavily Compressed Attention) plus Manifold-Constrained Hyper-Connections (mHC). As of 2026-08-14: price $0.14 / $0.28 per 1M input (cache-miss) / output tokens at a concurrency limit of 2500 — versus V4-Pro, roughly 3× cheaper input and 5× concurrency. (The model card explicitly cites "27% FLOPs / 10% KV cache vs. V3.2" for **V4-Pro**, not for Flash.)
- Strengths (benchmark values, unless stated otherwise = non-think column): Coding (HumanEval 69.5; Think High 88.4, Think Max 91.6), math (GSM8K 90.8), long context (LongBench-V2 44.7); Max mode mainly lifts knowledge-heavy tasks (SimpleQA-Verified 23.1 → 34.1).
- **Weakness in factual knowledge**: SimpleQA-Verified 23.1 (non-think) / 28.9 (high) / 34.1 (max) versus V4-Pro at 45.0 / 46.2 / 57.9 — knowledge-heavy prompts need their own grounding or belong on Pro.
- Further limits: FIM completion only non-thinking; JSON output occasionally returns empty `content` (adjust the prompt); Think Max wants ≥ 384K context. The Anthropic-compatible endpoint does not support document blocks (image blocks are now supported — but they are served by V4.1-Flash, which the ID is routed to), no `anthropic-beta`/`anthropic-version` headers, no `top_k`, no `cache_control`, no MCP tool use, and it ignores `budget_tokens`.

## Output & format conventions
- **1M context window, up to 384K output tokens.** Supported: JSON output, tool calls, Responses API, Anthropic API, Chat Prefix Completion (beta); FIM completion only in non-thinking mode. Latest version: `DeepSeek-V4-Flash-0731`. Since 2026-09-10, V4-Flash is retired; `deepseek-v4-flash` and `deepseek-v4-flash-vision-exp` are temporarily routed to DeepSeek-V4.1-Flash and billed at the Flash price. DeepSeek-V4-Flash-Vision-Exp (21 Aug 2026 to 10 Sep 2026, experimental) was, according to the vendor, on par with V4-Flash for text and additionally accepted images (up to 384 tokens per image).
- Base URLs: `https://api.deepseek.com` (OpenAI SDK), `https://api.deepseek.com/anthropic` (Anthropic SDK), `https://api.deepseek.com/beta` (prefill/FIM). On the Anthropic endpoint, `claude-haiku*`/`claude-sonnet*` map to `deepseek-flash` (V4.1-Flash); unknown model names also fall back to it.
- `response_format` only knows `text` (default) and `json_object` — **no `json_schema`**; strict schema adherence must be enforced via the prompt plus downstream validation. Sampling: `temperature` 0–2 (default 1), `top_p` up to 1 (default 1), max. 16 `stop` sequences, `logprobs` with `top_logprobs` 0–20, `tool_choice` none/auto/required/specific — `required` and named tools return HTTP 400 in thinking mode (usable only with `thinking: disabled`); `max_tokens` defaults 8K (non-thinking) / 64K (thinking) / 128K (`max`), maximum 384K; `frequency_penalty` and `presence_penalty` are no longer supported and remain ineffective.

## Migration notes
- **Migrating TO V4-Flash is no longer possible** — use the target `deepseek-v4.1-flash` (alias `deepseek-flash`) instead.
- **Migrating AWAY FROM DeepSeek-V4-Flash**: remove `thinking`/`reasoning_effort` parameters and any `reasoning_content` handling; if the target has no native reasoning mode, write explicit chain-of-thought instructions back into the prompt; if the target enforces `json_schema`, turn the in-prompt JSON example into a real schema and drop the mandatory literal "json"; only reintroduce `presence_penalty`/`frequency_penalty` if the target knows them; replace the `prefix: True` prefill with the target's prefill equivalent or a stop-sequence workaround. Moving from Flash to Pro within the family needs **no** prompt rewrite (same parameters, same context/output limits) — only knowledge-heavy prompts justify the roughly 3× more expensive input.
- **Migrating TO DeepSeek-V4-Flash** (historical, from `deepseek-v3` / `deepseek-chat` / `deepseek-r1` / `deepseek-reasoner`): the legacy IDs are **gone** — `deepseek-chat` and `deepseek-reasoner` were permanently unreachable after 24 Jul 2026, 15:59 UTC; official instruction: "Keep base_url, just update model to deepseek-v4-pro or deepseek-v4-flash." Concretely: (1) The chat-vs-reasoner model split becomes a **mode flag** — a former `deepseek-chat` prompt now needs `thinking: {"type": "disabled"}` or `reasoning.effort: "none"`; a former reasoner prompt needs nothing. (2) Delete `frequency_penalty`/`presence_penalty` from the request. (3) Remove `temperature`/`top_p` tuning from reasoning prompts — R1 advice such as "set temperature 0.6" has no effect. (4) If the prompt orchestrates tool calls, `reasoning_content` must now be passed back in the follow-up turn instead of stripped. (5) 1M context is the default and 384K output is possible — remove chunking/partial-summary scaffolding from the V3/R1 era without replacement. (6) Reorder the prompt: static instructions/references first, because prefix caching only rewards full prefix hits (inferred from the examples — unverified). (7) Replace "think step by step" scaffolding with `reasoning_effort` low/high/max — reasoning depth is now a parameter, not prompt text.
