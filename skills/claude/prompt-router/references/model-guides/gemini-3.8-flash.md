# Gemini 3.8 Flash

## Reasoning / Thinking
- Type: **always on**, depth set exclusively via the string enum `thinking_level` with `low | medium | high`, default **`medium`**. `minimal` is rejected for this model and returns an error — unlike `gemini-3.6-flash`, `gemini-3.5-flash` (deprecated, routed to 3.6 Flash) and `gemini-3.5-flash-lite`, which accept `minimal`.
- `thinking_budget` is superseded; there is no longer control via a token budget. Google describes the levels explicitly as "relative allowances for thinking rather than strict token guarantees" — i.e. no hard token guarantee.
- Level choice per the docs, tied to task types: low level for fact retrieval and classification ("Use minimal or low thinking for fact retrieval or classification"), default level for comparing concepts and creative reasoning ("Use default thinking for comparing concepts or creative reasoning"), highest level for advanced coding, mathematics and multi-step planning ("Use maximum thinking for advanced coding, math, or multi-step planning").
- Billing: "response pricing is the sum of output tokens and thinking tokens"; thought tokens are reported in `total_thought_tokens`. The full thought is billed even when only the summary is delivered ("Pricing is based on the full thought tokens the model needs to generate, despite only the summary being output").
- A thought signature is "An encrypted representation of the model's internal reasoning state." and carries reasoning continuity across turns. In stateful operation the server manages it ("The server automatically manages the conversation state, including all thought blocks and signatures"); in stateless operation **all** `thought` blocks must be sent back unchanged. Per the docs, the reasoning context carried across turns improves performance on complex multi-step tasks.
- Summaries via `thinking_summaries: "auto"`, switch off with `"none"`.

## Prompting style
- **Prompt briefly and directly.** "Be concise. Gemini 3.x responds best to direct, clear instructions." Per the docs, verbose prompt-engineering techniques from older models make the model "over-analyze" — strip carried-over step-by-step chains, role prose and repeated instructions.
- **Verbosity must be requested.** The default is low verbosity and directness; an explanatory or friendly tone belongs explicitly in the prompt.
- **Long-context layout:** data first, specific instruction or question at the **end**, and begin the question with an anchor such as "Based on the preceding information...".
- **No more sampling control:** `temperature`, `top_p`, `top_k` do not belong in the generation config. (For Gemini 3 in general, Google recommends leaving `temperature` at the default 1.0 — lowering it can cause looping or degraded performance in maths and reasoning.)
- **No assistant prefill:** remove prefilled model turns ("remove prefilled model turns"). Enforce format via Structured Outputs or System Instruction.
- Agentic: the launch post describes "greater diligence" on complex tasks, implemented by "executing extra reasoning steps, and calling tools iteratively". Set scope, stop criteria and tool budget explicitly rather than relying on self-restraint.

## Strengths & weaknesses (prompt-relevant)
- Strengths: "long-horizon software engineering, autonomous agents, and complex enterprise workflows" (wording from the model listing). The launch post calls it "our best reasoning and coding model yet, at the same speed and low cost of 3.7 Flash" and backs this with DeepSWE v1.1 ("outperforms most larger frontier models in autonomously solving complex engineering problems end to end, only at a fraction of the cost"), Vals Finance Agent V2, Harvey's Legal Agent Benchmark and 54.9% on HLE-Verified. The model card names the fields of use as "software engineering, agent tasks, and complex knowledge workflows".
- Tier placement: "Our most intelligent **Flash** model" — a superlative within the Flash line, not across the whole lineup. DeepMind positions it as "designed for cost-effective scaling of general-purpose, production-ready agents". The Pro tier (`gemini-3.1-pro-preview`, "Advanced intelligence, complex problem-solving skills") continues to exist alongside it; for maximum reasoning depth, 3.8 Flash is not automatically the top.
- It is the default model for Managed Agents (Antigravity).
- Weaknesses per the model card: usual hallucinations of foundation models; jailbreak susceptibility (mitigations recently strengthened); occasional slowness or timeouts; **higher token consumption at higher effort levels**; per Google it "can use more tokens on longer running and complex tasks, by design" — for everyday tasks lower `thinking_level`; slight regression in multilingual safety versus 3.7 Flash — with multilingual prompts, do not thin out guardrails in the prompt.
- Knowledge cutoff **March 2026**, in some domains only up to January 2025 — put time-critical facts in the prompt rather than asking the model for them.
- Known error class in tool calling: `Malformed_Function_Call` in combination with text before the tool call.

## Output & format conventions
- 1,048,576 input tokens / 65,536 output tokens. Input: text, image, video, audio, PDF → output text only.
- Supported: Structured Outputs, Function Calling, Caching, Code Execution, Search Grounding, URL Context, File Search, Grounding with Google Maps, Batch API, Computer Use (Preview), Flex and Priority inference. **Not** supported: audio generation, image generation, Live API. Per Google, image segmentation (pixel masks) is not supported in Gemini 3.x.
- Function calling: multimodal assets belong in the response payload; inline instructions are formatted with `\n\n`; with the `generateContent` API every `FunctionResponse` must carry `call_id` and `name`, with exactly one response per call and an exactly matching name.
- Multi-turn: the server-side `previous_interaction_id` is the prescribed default path; without it, the complete, unchanged history including thought signatures must be sent in `contents`.
- Price per 1M tokens (introductory price until 31 Dec 2026): input $0.75, output $3.75; from 1 Jan 2027 $1.50 / $7.50. Context caching $0.075 → $0.15 plus storage $0.50 → $1.00 per 1M tokens/hour. Batch API 50% cheaper. Same tiering as `gemini-3.6-flash`.
- SDK: according to the code example, multimodal function responses require an SDK "newer than 2.0.0" (https://ai.google.dev/gemini-api/docs/gemini-3).

## Migration notes
- **FROM gemini-3.8-flash**: translate `thinking_level` to the target's control model (`thinking_budget`, `reasoning_effort` or similar) and, if needed, size a token budget again; set `temperature`/`top_p`/`top_k` explicitly again if the target expects sampling; remove the `previous_interaction_id` and thought-signature logic and manage history yourself again; re-enrich terse prompts if the target needs explicit step-by-step scaffolding; re-evaluate tone and verbosity instructions (they only compensate for the terse 3.8 default); align multimodality — audio, video and PDF input are not available everywhere; check 1M input / 64k output against the target's limits.
- **TO gemini-3.8-flash**: remove `temperature`, `top_p`, `top_k` and `candidate_count` from the generation config; replace `thinking_budget` with `thinking_level` — `minimal` does not exist here and throws an error, so raise `minimal` paths coming from 3.6 Flash / 3.5 Flash(-Lite) to `low` and re-measure latency and quality; remove prefilled model turns; move multi-turn to `previous_interaction_id` or pass thought signatures through unchanged; add `call_id` and `name` to every `FunctionResponse`; remove verbose prompt-engineering remnants; with long contexts put data first and the question at the end; add explicit tone and length instructions if the previous output was more conversational; do not migrate segmentation workloads here.
- Specifically **from `gemini-3.7-flash`**: same (last listed) list price, same token limits, same `low | medium | high` ladder with default `medium` — the migration is at its core the id swap plus the function-calling and turn-validation points above. Since 8 Oct 2026, `gemini-3.7-flash` is deprecated; "API requests to `gemini-3.7-flash` are automatically routed to `gemini-3.8-flash`" — a prompt tuned for 3.7 therefore already runs on 3.8; only the model string needs updating. Google names a more token-efficient alternative: "Alternatively, Gemini 3.6 Flash remains supported".
