# /refine

Use this command to improve an existing prompt, brief, plan, research question, or workflow artefact.

## Command

```text
/refine

Task: [PROMPT / BRIEF / PLAN / RESEARCH QUESTION]

Do not research.
Do not recommend.
Do not enter solution mode.

Refine the artefact against the gated research workflow.

Assess:
1. Objective clarity
2. Scope boundaries
3. Missing constraints
4. Hidden assumptions
5. Contradictions
6. Evidence standard
7. Compatibility and safety requirements
8. Decision criteria
9. Output format
10. Reversibility and validation plan

Return:
1. Revised artefact
2. Change log
3. Assumptions removed or corrected
4. Questions still requiring my input
5. Validation cases
6. Proposed next gate
```

## Gate

This command may operate at any gate, but it must not skip a gate or produce a recommendation before G4 is complete.
